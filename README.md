# 截图头像工坊（原型）

把手机截图（尤其是抖音截图）自动「去掉多余边缘 → 保留完整画面」的本地工具。
**纯前端、无后端、图片不出本机**，直接用浏览器打开 `index.html` 即可。
默认**不裁掉画面内容**（输出保持原比例，短边 1080），需要 1:1 头像时再勾选方形。

![编辑器预览](docs/editor.png)

## 为什么不是「人脸识别裁剪」

真实需求是：截图里往往有上下黑边、白色留白、状态栏、右侧图标、底部字幕，用户只想留下中间那张图；
而且很多图根本没有脸（风景、宠物、文字图、二创图）。所以核心是**找内容区域**，不是找人脸。

## 怎么用

1. 双击打开 `index.html`（Chrome / Edge，手机浏览器也可以）。
2. 把截图拖进去，或 `Ctrl + V` 粘贴，或点「选择图片」，可一次多张。
3. 默认输出「完整画面」：只去掉黑边/状态栏/字幕，画面一点不切，短边 1080。
4. 需要 1:1 头像时勾选「裁成 1:1」——会按智能构图切掉画面边缘（这一步才会裁内容）。
5. 多张时点「全部下载」会打成一个 zip（浏览器不允许连续弹多个下载）。
6. 没截图也可以点「看示例」，会现场画一张仿抖音截图（黑边 + 状态栏 + 字幕）演示。
   或者直接打开 `index.html#demo`，自动载入示例并进入编辑器（用于截图/演示）。
7. 编辑页里：**白框内 = 成品**，框外的紫色斜纹是原截图里会被去掉的部分；右侧「成品预览」显示的就是下载下来的图，
   不用再猜成品带不带黑边。页面标题旁显示版本号（当前 `v0.4.0`），方便确认刷新成功。

## PWA / 手机安装（Android）

PWA 需要 **HTTPS 或 localhost** 才能启用 Service Worker（直接双击 `file://` 不行）。

**部署（二选一）**

- Netlify Drop / Vercel：把整个 `avatar-crop` 文件夹拖进去，得到网址；
- GitHub Pages：推到仓库，Settings → Pages 选分支根目录。

**Android 安装**

1. Chrome 打开网址；
2. 点页面右上「安装到桌面」（或 Chrome 菜单 → 安装应用）；
3. 主屏出现图标，全屏运行、离线可用；
4. 相册里选截图 → 分享 → 头像工坊，可直接导入（`share_target`）。

**更新**

改完代码把 `index.html` 里的 `?v=`、`sw.js` 的 `VERSION`、`app.js` 的 `APP_VERSION` 同步加一，重新部署；Service Worker 会自动清旧缓存。

**图标地基**

`assets/icons/` 里有 5 个尺寸和说明文档，以后有设计稿直接同名覆盖，不用改代码；也可以用 `tools/make_icons.py` 重新生成（品牌色在脚本顶部）。

## 视觉方向

**暗房 / 接触印相**：暖炭黑台面、骨白相纸、安全灯琥珀作为唯一强调色；编号、细线与等宽微标签。
产品事实记录在 `PRODUCT.md`，视觉契约/token 在 `DESIGN.md`。

- 图标：暖炭黑底 + 骨白裁切角 + 琥珀圆环（`assets/icons/`，同名覆盖即可替换）；
- 无外部字体、无外部图片依赖，离线可用；
- 已跑 Impeccable 设计检测器，仅剩一条浅色渐变近似告警（实际文本落在深色底上）。

## 算法（不依赖任何模型/库）

`src/auto-crop.js`：

1. **取边底色**：从每条边往里 0.6% 的位置取中位色，避开手机截图里常见的细边框。
2. **逐层去边**：从每条边往里逐行/逐列统计「与底色明显不同」的像素占比，低于阈值就判为空白/黑边并裁掉；
   另外，整行颜色高度一致、且接近纯黑/纯白的均匀条也直接当边框。每轮从当前边缘重新取底色，最多 4 轮，
   所以「细白边框 → 黑边 → 状态栏」这种多层结构也能一层层剥掉。单侧最多裁 45% 左右，防止把图裁没。
   **深色/浅色模式**：根据整图边缘底色判断查看器背景是深色还是浅色。深色模式下只把暗色区域当空白，
   遇到亮色区域立刻停——否则白底插画（画面本身大面积白色）会被当成白边裁掉。
3. **清稀疏 UI 条**：如果检测到了边框（说明是截图），继续清掉紧贴四边、且「纯色底像素 ≥ 50%」的窄条
   ——状态栏、底部字幕正是「纯色底 + 稀疏文字」。每侧最多再清 15%。只收缩，不扩张。
4. **深色底带扫描**：从四边逐行/列扫掉「颜色几乎一致、且偏暗」的带（截图查看器的黑边/深灰底），
   允许跨过很窄的进度条/图标，遇到有纹理的画面内容就停。这样既去掉查看器底，也不会把画面里
   带纹理的深色区域（雪地、黑衣服）误裁掉。
5. **方形（可选）**：勾选 1:1 时，在去边后的区域按边缘能量算「画面重心」，给一个略偏上的方形框，
   智能偏移最多 12%，避免把画面甩到边角；也可切「居中」。
6. 纯色图 / 无边框照片有保护：整图几乎没有内容时不做任何裁剪。

## 已知边界 / 下一步

- 照片下方如果还有一块**和画面颜色接近**的信息区，可能不会被去掉；默认优先「不裁掉画面」。
- 抖音右侧点赞/评论图标是压在照片上的 UI，目前保留；去掉它需要抠图/修复算法。
- 超长截图（滚动截图）会整块保留。
- 下一步（如果继续做）：
  - **训练本地 AI 检测模型**（105 张真实截图已放在 `dataset/images`），替代逐张调阈值；
  - PWA 之后再用 Capacitor 套一个 APK（同一套代码）；
  - 背景移除/换底色；
  - 合规：人脸是敏感个人信息，当前方案全程本地处理，不存储、不上传，风险最低。

## 目录

```
index.html          页面
style.css           样式（暗房视觉系统）
manifest.webmanifest  PWA 清单（图标、主题色、分享目标）
sw.js               Service Worker（离线缓存 + 接收 Android 分享）
PRODUCT.md          产品事实
DESIGN.md           视觉方向与 token
assets/icons/       PWA 图标（含源 SVG、README 与替换说明）
tools/make_icons.py 生成图标
src/auto-crop.js    自动去边 + 可选方框算法（纯函数，可单测）
src/zip.js          极简 ZIP 打包（store）
src/app.js          交互逻辑
dataset/images/     105 张真实截图（AI 训练集）
inbox/              以后放待测截图到这里
test/auto-crop.test.js  算法单测（node 运行）
test/zip.test.js        ZIP 单测
test/make_sample.py     生成仿抖音截图（Pillow）
test/detect_sample.js   端到端跑算法
test/make_preview.py    导出裁剪结果和标注图
test/decode_image.py    截图 → raw（回归用）
test/detect_image.js    在指定 raw 上跑算法
test/preview_image.py   标注图 + 裁剪结果
test/verify_image.js    模拟浏览器“先缩小到 2000 再识别”的流程
test/pwa_check.js       通过 CDP 检查 Service Worker / 缓存状态
test/capture.js         通过 CDP 截取桌面/移动端截图
docs/               预览图（编辑器、标注图、裁剪结果、真实截图效果）
```

运行单测（需要 Node）：

```bash
node test/auto-crop.test.js
node test/zip.test.js
```

端到端验证（需要 Pillow，先造图再跑算法）：

```bash
python test/make_sample.py        # 生成 test/sample.png + sample.raw
node test/detect_sample.js        # 输出裁剪框到 test/detect.json
python test/make_preview.py       # 生成 test/avatar.png / test/marked.png
```
